## 🚀 Deploy ke GitHub Pages
1. Buat repo baru di GitHub
2. Upload fail `index.html` ke repo
3. Pergi ke **Settings → Pages**
4. Set source: `main` branch, folder `/` (root)
5. Klik **Save** — URL akan dipaparkan dalam beberapa minit
